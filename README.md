# 📊 Sales Prediction Using Python – Machine Learning

### 🚀 CodeAlpha Data Science Internship | Task 3

## 🌟 Project Overview

Turning marketing data into meaningful sales predictions!

This project focuses on predicting sales using Machine Learning based on advertising expenditure, marketing platforms, and target customer segments.

A **Random Forest Regression** model is used to analyze the data and estimate sales.

## 🎯 Project Objectives

- Analyze advertising and sales data.
- Perform data cleaning and preprocessing.
- Explore data using visualizations.
- Build a Machine Learning regression model.
- Predict sales based on marketing factors.
- Understand how advertising influences sales.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## ⚙️ Project Workflow

1. Dataset Collection
2. Data Exploration
3. Data Cleaning and Preprocessing
4. Exploratory Data Analysis (EDA)
5. Model Training
6. Sales Prediction
7. Model Evaluation
8. Business Insights

## 🤖 Machine Learning Algorithm

**Random Forest Regressor**

Random Forest Regression combines multiple decision trees to predict numerical values. It is used here to estimate sales based on advertising-related features.

## 📈 Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)
